# Protected comparator evidence contract

A publicly displayed price is not a delivered, protected, purchasable quote. The existing public catalog uses only a comparator with a matching exact identity (contradictory identifiers rejected), approved source-specific collection, public projection and durable retention rights, a current timestamp within the source's approved age (maximum 24 hours), a verified fixed-price in-stock offer, reputable verified seller, item-specific return eligibility, and verified shipping, fees and tax for the public San Antonio delivery scope. Never store actual user address or checkout session. A general return policy is context only. Strictly more than 50% savings is calculated on the delivered total, with auction premium, estimated tax and lot fee included.

Current eBay and Best Buy adapters remain disabled. API credentials alone are insufficient. Best Buy API terms constrain caching to temporary display use; don't add API content to durable public artifacts or Git without separate authorization. A provider with display-only rights needs a distinct expiring serving path. Do not place account credentials in any public artifact. No new API or publisher enabled by this change.

References: https://developer.ebay.com/api-docs/buy/browse/overview.html ; https://developer.bestbuy.com/terms ; issue #70.
